# Iklimara — revisi materi, desain tetap

Website ini menggunakan desain, palet warna, logo, gambar, navigasi utama, dan struktur dari ZIP Iklimara sebelumnya. Perubahan difokuskan pada penambahan materi dari dokumen Word `Pages pemweb.docx` yang belum terwakili secara lengkap, terutama rincian gas rumah kaca, data emisi, jejak karbon/CO₂e, studi tematik masyarakat pesisir, kelompok rentan, dan keterkaitan SDG 13.

## Halaman
1. `index.html` — Beranda
2. `iklim.html` — Mengenal perubahan iklim
3. `emisi.html` — Penyebab dan jejak karbon
4. `dampak.html` — Dampak perubahan iklim
5. `mitigasi.html` — Mitigasi perubahan iklim
6. `aksi.html` — Adaptasi dan aksi iklim
7. `tentang.html` — Tentang dan daftar pustaka

Navigasi Sebelumnya/Berikutnya ditambahkan di bawah setiap halaman menggunakan tautan HTML biasa. Tidak ada JavaScript atau file `.js`. Buka `index.html` di browser atau gunakan Live Server. Jangan pisahkan folder `css` dan `images`.
